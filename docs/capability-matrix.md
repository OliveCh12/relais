# Capability validation matrix

This is a validation plan, not a universal hardware inventory. The initial foundation matrix preceded device access. Since then, the iPhone has reported native profiles including 4K120 and opened Video/Cinematic at 4K HDR30; see [current camera evidence](research/native-camera-capabilities.md). A reported profile still does not prove successful file recording. Physical Android validation remains pending.

Expose a feature only after the native engine returns a valid combination. Stock-camera specifications do not establish third-party access.

| Feature                                  | iOS detection / API                                               | Android detection / API                                       | Relais status / fallback                                                                                                                                                  |
| ---------------------------------------- | ----------------------------------------------------------------- | ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Local recording + preview                | AVFoundation output combination                                   | CameraX use-case combination                                  | Reduced native preview feeds WebRTC; original stays on the capture phone. Reject invalid combinations. Hardware proof of simultaneous recording + streaming still pending |
| 4K30 / HEVC                              | Capture format + codec                                            | Encoder/QualitySelector profiles                              | Prefer when supported; otherwise 1080p60/30, H.264                                                                                                                        |
| 4K60/120                                 | Format/frame-rate/encoder combination                             | Format/frame-rate/encoder combination                         | Hardware-derived choices; no assumed support or recording proof; fallback 4K30/1080p30                                                                                    |
| Ultra-wide/wide/tele                     | DiscoverySession                                                  | Logical/physical camera IDs                                   | Native inventory; fallback default rear camera                                                                                                                            |
| Zoom 2x/8x                               | videoZoomFactor                                                   | zoomRatio                                                     | Do not equate factors with physical lenses; fallback 1x                                                                                                                   |
| Torch / exposure                         | hasTorch and active device support                                | CameraControl                                                 | Per-camera controls; hide unsupported torch, retain automatic exposure                                                                                                    |
| HDR / Dolby Vision                       | Format + color space                                              | DynamicRange + session combination                            | HLG support connected; no Dolby Vision certification; SDR fallback                                                                                                        |
| ProRes / Log 2                           | Format, codec and storage validation                              | ProRes not offered                                            | Not implemented; HEVC/H.264 fallback                                                                                                                                      |
| Pro Video Storage                        | Proposed iOS 27 APIs require SDK verification/availability guards | Not applicable                                                | Not implemented; ordinary local writing with storage checks                                                                                                               |
| Deferred Start                           | isDeferredStartSupported                                          | No assumed equivalent                                         | Future optimization; prepare outputs before start                                                                                                                         |
| Dual Capture                             | isMultiCamSupported + costs                                       | Concurrent-camera support, no assumed parity                  | Outside V1; one camera                                                                                                                                                    |
| Center Stage / square aspect             | Applicable front formats and supportedDynamicAspectRatios         | No assumed equivalent                                         | No dynamic aspect changes during recording; fixed file aspect                                                                                                             |
| HDR + 60 fps + stabilization             | Active-format combination                                         | Session/Feature Group validation                              | Expose only validated combinations; remove unsupported options                                                                                                            |
| Hybrid AE / temperature-tint / RAW14     | Not required                                                      | SDK/device capability checks                                  | Outside foundation; native AE/AWB and ordinary video                                                                                                                      |
| Extensions / Video Boost / Magic Capture | Not applicable                                                    | isExtensionSupported does not grant all stock modes           | No unsupported vendor-mode UI; standard pipeline                                                                                                                          |
| H.264 hardware preview                   | Negotiated codec and encoder/decoder profiling                    | Same                                                          | Target; explicit failure when budgets cannot be met                                                                                                                       |
| Thermal / battery                        | ProcessInfo/pressure + UIDevice                                   | PowerManager thermal + BatteryManager                         | Contract events exist; native telemetry pending, unknown values stay unknown                                                                                              |
| LAN without internet                     | Local-network permission                                          | INTERNET at current target; target 37 permission work pending | Topology-dependent; explain isolation and allow another network                                                                                                           |

The historical remote-control engine exposes `fileQualities` within each lens, binding resolution, fps, HDR and codec. Its fixtures are explicitly labeled demos and never enable `canRecord` or `canPreview`. They are separate from real local-camera profile discovery.
